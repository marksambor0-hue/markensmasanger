# MARKENS — правила разработки для Gemini

- Это существующий MARKENS v30.1: Electron-приложение Windows с текущим `index.html`, Firebase и уже работающими функциями.
- Сначала изучай текущую структуру и код. Меняй только то, что нужно для конкретного запроса.
- Не заменяй проект на React/Vite или другой шаблон и не переписывай интерфейс целиком без прямого запроса.
- Сохраняй текущую авторизацию, чаты, Firebase-конфигурацию и совместимость с Windows 10/11 x64. Не меняй имена существующих файлов или Firebase-проект без необходимости.
- Не добавляй секреты, токены, приватные ключи или пароли в репозиторий.
- Не включай `nodeIntegration` и не отключай `contextIsolation` ради удобства. Не разрешай микрофон, камеру или демонстрацию экрана автоматически без явной необходимости и действия пользователя.
- После изменений проверь доступные команды `package.json`; Windows-пакет должен собираться командой `npm run dist` и создавать `dist/MARKENS_Setup.exe` и `dist/MARKENS_Portable.exe`.
- Не утверждай, что проверка прошла, если команда фактически не запускалась. Если сборка падает, исправляй первопричину, а не скрывай ошибку.
- Не удаляй рабочие функции ради зелёного статуса CI. Если запрос конфликтует с существующей архитектурой, выбирай минимальное безопасное изменение.
