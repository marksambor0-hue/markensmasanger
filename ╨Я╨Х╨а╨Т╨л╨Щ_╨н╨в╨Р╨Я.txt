MARKENS — ПЕРВЫЙ БЕЗОПАСНЫЙ ЭТАП

Этот архив нужен для первой загрузки исходников в обычный репозиторий GitHub.
При первом push GitHub Actions проверит исходники и попробует собрать тестовый Windows-установщик.
Публикация официального релиза намеренно выключена, чтобы не отправить обновление пользователям до проверки сборки.

ВАЖНО:
- Распакуй архив.
- Загружай содержимое архива в корень существующего репозитория, сохраняя папку .github/workflows и scripts.
- Не загружай сам ZIP в репозиторий вместо файлов внутри него.
- После загрузки открой вкладку Actions в GitHub и посмотри результат workflow.
- Если Windows-сборка успешна, пришли мне результат/скрин. Тогда подготовим финальную версию workflow, которая включает публикацию релизов и автообновление.
- Если сборка не прошла, ничего не публикуется; по тексту ошибки можно исправить проблему.

Это не подтверждение, что обновление уже работает на установленном компьютере. Реальная Windows-сборка и проверка обновления ещё впереди.
